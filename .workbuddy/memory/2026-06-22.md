# 2026-06-22

## 理解项目并运行

- 项目：SysMind —— React 19 + Vite 6 + TypeScript + Tailwind CSS v4 系统映射可视化工具
- 支持 Web（Vite dev server）和 Electron 桌面版两种运行方式
- 正确启动命令：在项目目录用 PowerShell 执行 `npm run dev`（底层调用 `vite --port=3000 --host=0.0.0.0`）
- 注意：在 Bash 中直接调用 `npx vite` 或通过 `.bin/vite` 脚本会因 shell shebang 格式不兼容而失败；需通过 PowerShell 的 npm 来调用
- 开发服务器启动后地址：http://localhost:3000
- 核心源码：`src/App.tsx`（主逻辑）、`src/components/`（ShortcutsModal）、`src/lib/`（constants、translations、graphGeometry 等工具库）
