# SysMind 项目功能文档

SysMind 是用于绘制系统关系、思维结构和项目规划图的可视化编辑工具。

## 功能

- 创建、编辑、拖动和删除节点
- 创建单向、反向、双向和无箭头连接
- 支持键盘快捷键、撤销和重做
- 支持 JSON 导入、导出和本地保存
- 支持画布缩放、平移、搜索和多选
- 支持中英文界面与浅色、深色主题

## 三个交付目标

| 目标 | 目录 | 构建命令 | 产物 |
| --- | --- | --- | --- |
| 本地 Web | 仓库根目录 | `npm run dev` | `http://localhost:3000` |
| GitHub Pages | 仓库根目录 | `npm run build:pages` | `forpages/` |
| Windows 桌面版 | `fortauri/` | `npm run tauri:build` | `fortauri/release/SysMind-tauri-portable-win-x64.zip` |

## 依赖安装

本地 Web 和 GitHub Pages 使用根目录依赖：

```bash
npm install
```

Tauri 使用自己的依赖，并需要 Rust/Cargo 和 Windows WebView2 Runtime：

```bash
cd fortauri
npm install
npm run tauri:build
```

GitHub Pages 工作流位于 `.github/workflows/deploy.yml`，会执行 `npm run build:pages` 并上传 `forpages/`。
