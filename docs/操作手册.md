# SysMind 操作手册

本文档基于当前项目实现整理，说明系统中的主要操作方式、不同焦点状态下的行为，以及各操作对应的效果。

## 1. 基本概念

### 1.1 画布对象

- 节点：承载文本内容的基础对象。
- 连线：连接两个节点，也可以处于“未完成连接”的临时状态。
- 焦点：当前被键盘操作优先作用的对象，只能是“空焦点 / 节点焦点 / 连线焦点”之一。
- 编辑态：当节点文本或连线文本进入输入状态后，大部分快捷键会暂停，键盘用于文本输入。

### 1.2 节点类型

- `default`：默认节点。
- `text`：纯文本节点，弱化边框和背景。
- `note`：提示型节点，偏黄色。
- `warning`：警示型节点，偏红色。

### 1.3 连线类型

- `forward`：单向正向箭头。
- `backward`：单向反向箭头。
- `both`：双向箭头。
- `none`：无线头。

## 2. 界面区域说明

### 2.1 顶部控制区

- 撤销 / 还原。
- 语言切换。
- 加载、导出、导出图片、新建、保存。
- 设置按钮：打开设置面板，在面板中配置主题和快捷键。

### 2.2 左上快捷提示区

- 上方固定显示“通用操作”。
- 下方根据当前状态显示特殊操作：
  - 空焦点操作
  - 节点焦点操作
  - 连线焦点操作
  - 节点文本输入
  - 连线文本输入

### 2.3 右下角连线样式提示

- 当焦点在连线上时显示。
- 用于提示当前连线箭头样式以及 `Tab` 可循环切换样式。

## 3. 鼠标操作

### 3.1 画布操作

- 左键点击空白画布：清除当前焦点和选择。
- 左键在空白处拖拽：框选节点。
- 右键按住拖拽：平移画布。
- 触控板双指拖动：平移画布。
- 触控板捏合，或 `Ctrl/Cmd + 滚轮`：缩放画布。

### 3.2 节点操作

- 左键点击节点：将节点设为焦点。
- 左键拖拽节点：移动节点。
- 若当前是多选状态，拖动任一已选节点时，会整体移动当前选中的节点集合。

### 3.3 连线操作

- 左键点击连线：将连线设为焦点。
- 左键拖拽连线控制柄：
  - 拖动末端控制点：修改连线终点，可以重新吸附到其他节点。
  - 拖动起点控制点：从另一端重新接回，并自动反转箭头方向。
  - 拖动中间弯曲控制点：调整连线弯曲程度。
- 连线末端或起点拖到某个节点上松开：连线会吸附并完成连接。
- 若没有吸附到节点：连线会保持为未完成连接状态。

### 3.4 文本编辑

- 节点焦点下点击并进入编辑，或使用快捷键进入编辑后，可直接修改节点文字。
- 连线焦点下进入编辑后，可修改连线标签文本。
- 输入框失焦时自动结束编辑。

## 4. 焦点与键盘操作逻辑

系统的大部分键盘操作与当前焦点状态有关。

### 4.1 通用操作

这些操作在几乎任何非编辑状态下都可使用：

| 操作 | 默认快捷键 | 效果 |
| --- | --- | --- |
| 放大 | `Ctrl/Cmd + =` | 画布放大 |
| 缩小 | `Ctrl/Cmd + -` | 画布缩小 |
| 重置缩放 | `Ctrl/Cmd + 0` | 缩放恢复到 100% |
| 移动焦点 | `方向键` | 在节点和连线之间按空间方向切换焦点 |
| 撤销 | `Ctrl/Cmd + Z` | 撤销上一步 |
| 还原 | `Ctrl/Cmd + Y` | 恢复被撤销的操作 |
| 打开设置 | `Shift + ?` | 打开设置面板 |

说明：

- 当没有焦点时，方向键会优先把焦点定位到“当前视口中心附近最近的节点”。
- 当已有焦点时，方向键会根据几何方向在节点和连线之间跳转。

### 4.2 空焦点状态

空焦点时的特殊操作：

| 操作 | 默认快捷键 | 效果 |
| --- | --- | --- |
| 创建节点 | `Enter` | 在当前视口中心创建一个新节点，并立即进入文本编辑 |

### 4.3 节点焦点状态

节点获得焦点后，可以执行以下特殊操作：

| 操作 | 默认快捷键 | 效果 |
| --- | --- | --- |
| 编辑文字 | `Space` | 进入节点文本编辑 |
| 从当前节点创建连线 | `Enter` | 创建一条从当前节点出发的未完成连线，并将焦点切到该连线 |
| 在下方创建节点 | `Shift + Enter` | 在当前节点下方创建新节点，并立即进入编辑 |
| 返回连线 | `Ctrl/Cmd + Enter` | 从“上一个来源节点”向当前节点附近生成一条回连 |
| 切换节点样式 | `Tab` | 在 `default -> text -> note -> warning` 间循环 |
| 移动节点 | `Ctrl/Cmd + 方向键` | 以网格步长移动当前节点 |
| 删除 | `Delete` / `Backspace` | 删除当前节点及其相关连线 |

补充说明：

- “返回连线”优先使用当前节点的来源节点；如果没有显式来源，则使用上一个聚焦过的节点。
- 在节点聚焦状态下直接输入字符，也会自动进入编辑态。

### 4.4 连线焦点状态

连线获得焦点后，可以执行以下特殊操作：

| 操作 | 默认快捷键 | 效果 |
| --- | --- | --- |
| 编辑文字 | `Space` | 进入连线文本编辑 |
| 完成连线 / 创建目标节点 | `Enter` | 若连线尚未连接到目标节点，则在当前终点处创建目标节点并完成连接；若已连接，则跳转焦点到目标节点 |
| 切换连线样式 | `Tab` | 在 `forward -> backward -> both -> none` 间循环 |
| 搜索目标节点 | `/` | 打开搜索面板，为当前连线快速指定目标节点 |
| 移动连线终点 | `Ctrl/Cmd + 方向键` | 未完成连线时移动临时终点；已连接连线时移动目标节点 |
| 删除 | `Delete` / `Backspace` | 删除当前连线 |

补充说明：

- 当连线处于“未完成连接”状态时，`Enter` 会在当前终点位置创建一个新节点，并自动接上。
- 当连线已经连接到目标节点时，`Enter` 不再创建节点，而是把焦点转到目标节点。
- 连线样式切换同时会记住最近一次的箭头风格，新建连线会尽量沿用。

### 4.5 节点文本输入状态

节点文本输入时，键盘主要用于输入文本。

| 操作 | 按键 | 效果 |
| --- | --- | --- |
| 输入文字 | 任意普通字符 | 修改节点内容 |
| 完成编辑 | `Enter` / `Esc` | 结束编辑并保留当前内容 |
| 失焦完成 | 点击其他区域 | 结束编辑并保留当前内容 |

说明：

- 进入编辑态后，常规对象快捷键会暂停，避免误触发。

### 4.6 连线文本输入状态

连线文本输入时：

| 操作 | 按键 | 效果 |
| --- | --- | --- |
| 输入文字 | 任意普通字符 | 修改连线标签内容 |
| 完成编辑 | `Enter` / `Esc` | 结束编辑并保存标签内容 |
| 失焦完成 | 点击其他区域 | 结束编辑并保存标签内容 |

## 5. 搜索连接目标

当焦点在连线上时，可按 `/` 打开搜索面板。

### 5.1 搜索过程

- 输入关键字：按节点文本过滤候选节点。
- `方向键上 / 下`：切换候选项。
- `Enter` 或 `Tab`：把当前连线连接到所选节点。
- `Esc`：关闭搜索面板。
- 鼠标点击候选项：立即连接到该节点。

### 5.2 搜索结果效果

- 选择目标节点后，当前连线的终点会吸附到该节点。
- 连线会自动重新计算一个较合适的弯曲值，尽量减少与现有连线重叠。

## 6. 多选、框选与批量移动

### 6.1 框选

- 在空白区域按住左键拖拽，可绘制选择框。
- 当前实现中，框选主要选中节点。
- 如果最终只选中一个节点，系统会自动把焦点切到该节点。
- 如果选中多个对象，焦点会置空，但选择仍保留。

### 6.2 批量拖动

- 当多个节点处于选择状态时，拖动其中任意已选节点，会整体移动该批节点。
- 如果选择中包含某些未完成连线，相关临时终点也会跟着一起移动。

## 7. 画布导航与视角行为

### 7.1 缩放

- 可通过快捷键、触控板捏合、`Ctrl/Cmd + 滚轮` 缩放。
- 缩放时以指针位置为中心进行放缩，便于局部查看。

### 7.2 平移

- 右键拖拽画布平移。
- 触控板双指拖动平移。

### 7.3 自动聚焦

- 某些情况下，当焦点切换到连线时，画布会自动把视图居中到该连线附近。
- 正在拖动节点、控制点、曲率控制柄时，不会强制自动居中，避免打断操作。

## 8. 文件操作

### 8.1 加载

- 点击顶部 `加载` 按钮可导入 `.json` 数据。
- 导入内容包括：
  - 节点
  - 连线
  - 画布偏移和缩放
  - 默认偏移量
  - 快捷键设置

### 8.2 导出 JSON

- 点击顶部 `导出` 按钮，会把当前画布保存为 JSON 文件。
- JSON 中包含当前全部结构数据与部分界面设置。

### 8.3 保存

- 点击顶部 `保存` 按钮：
  - 如果当前文件来源支持直接覆盖写入，则写回原文件。
  - 如果环境不支持原位保存，则会回退为下载导出。

### 8.4 新建

- 点击顶部 `新建` 按钮前，系统会先尝试保存当前内容。
- 保存成功后清空当前画布，回到空白状态。

## 9. 导出图片

### 9.1 导出行为

- 点击顶部 `导出图片` 按钮，会将整张内容图导出为 PNG。
- 导出范围基于所有节点、连线和标签的实际内容边界，不受当前窗口可见区域限制。
- 导出尺寸保持整体内容原始比例，而不是当前视口比例。

### 9.2 导出效果

- 当前主题会影响导出背景与网格颜色。
- 节点、连线、标签、箭头都会按完整内容一并输出。
- 若内容过大，导出过程会自动限制最大画布尺寸，避免浏览器直接失败。

## 10. 设置面板

点击顶部 `设置` 按钮，打开设置面板。

### 10.1 外观设置

- 可切换：
  - 浅色模式
  - 深色模式
- 点击底部 `保存` 后生效并写入本地存储。

### 10.2 快捷键设置

- 可重新绑定以下动作：
  - 新建节点
  - 从节点新建连线
  - 下方新建节点
  - 返回连线
  - 编辑文字
  - 删除
  - 撤销 / 还原
  - 缩放相关
  - 方向键导航
  - 切换样式
  - 搜索连接
  - 打开设置

### 10.3 快捷键录制规则

- 点击某个快捷键按钮后进入录制状态。
- 直接按下新的组合键即可替换。
- 若发生冲突，系统会标记冲突项，并阻止保存。
- `新建节点` 与 `从节点新建连线` 可以共用同一个按键，因为二者作用在不同焦点状态。

## 11. 深色模式表现

深色模式下，以下内容会跟随主题变化：

- 画布背景与网格
- 空画布提示文字
- 顶部面板、提示面板、搜索面板、设置面板
- 节点背景、边框、文本
- 连线颜色、箭头、控制点
- 连线标签与编辑输入框
- 导出图片背景与标签底色

## 12. 常见操作流程示例

### 12.1 从零开始建立一条关系

1. 在空焦点下按 `Enter` 创建第一个节点。
2. 输入节点文字，按 `Enter` 完成编辑。
3. 再按 `Enter` 从该节点发起一条连线。
4. 再按 `Enter` 在连线终点创建目标节点。
5. 输入目标节点文本并完成编辑。

效果：

- 得到两个节点和一条已经连接完成的连线。

### 12.2 给已有节点补一个下游节点

1. 选中某节点。
2. 按 `Shift + Enter`。
3. 输入新节点内容。

效果：

- 在当前节点正下方新增一个节点，并立即进入编辑。

### 12.3 将连线改接到其他节点

1. 点击连线使其获得焦点。
2. 拖动连线末端控制点。
3. 拖到目标节点上后松开。

效果：

- 当前连线终点重新吸附到新的目标节点。

### 12.4 快速把未完成连线接到指定节点

1. 让连线处于焦点状态。
2. 按 `/` 打开搜索面板。
3. 输入节点关键字。
4. 用上下方向键选择候选项，按 `Enter` 确认。

效果：

- 当前连线自动连接到所选节点。

### 12.5 创建回路或回连

1. 先沿着流程创建几个节点。
2. 聚焦到后续节点。
3. 按 `Ctrl/Cmd + Enter`。

效果：

- 系统会尝试从来源节点或上一个节点生成一条回连。

## 13. 当前实现中的注意事项

- 框选当前主要作用于节点，不直接框选普通连线。
- 文本输入时，快捷键逻辑会让位于文本编辑。
- 已连接连线执行 `Ctrl/Cmd + 方向键` 时，移动的是目标节点本身，而不只是视觉终点。
- 连线文本为空时不会显示标签框。
- 部分快捷键可在设置面板中自定义，文档中的按键为默认值。
